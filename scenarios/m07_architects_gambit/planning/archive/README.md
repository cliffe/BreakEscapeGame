# Archived branch designs — not the current mission

These three documents (Option B "Data Apocalypse", Option C "Supply Chain Infection", Option D
"Corporate Warfare") were full playable-branch designs written for an architecture in which m07
offered four selectable operations, each with its own facility, rooms, cast, VM challenge and
confrontation. That architecture was cut: m07 is now one playable operation — the Pacific Northwest
grid facility, formerly Option A — plus a delegation choice covering the other three crises, which
resolve off camera. The material here is retained because it is where the delegation briefs and the
debrief outcomes get their target detail and casualty arithmetic, and because the cells and named
leads it establishes are still canon for later missions. Treat it as source material only. **None of
it describes the mission being built.**
