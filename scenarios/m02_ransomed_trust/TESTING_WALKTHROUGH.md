## Recovery Console wiring (was a blocker — now fixed)

Terminals in Break Escape are **minigames, not ink**. The Hospital Recovery Console (`type: backup_recovery`) launches the backup-recovery minigame, which writes globals only: `backup_recovery_source` (chosen source id), `backup_restore_initiated`, `backup_reinfected`. It does **not** itself complete tasks.

Task completion is driven by Agent 0x99 eventMappings that watch those globals (same pattern as sis01's Helen Carver on `backup_restore_initiated`):

- `global_variable_changed:backup_restore_initiated` (`value === true`) → `completeTask: initiate_backup_recovery`
- `global_variable_changed:backup_recovery_source` (`value === 'ransom_payment'`) → `setGlobal paid_ransom=true, ransom_decision_made=true`, `completeTask: make_ransom_decision`
- `global_variable_changed:backup_recovery_source` (`value === 'offline_keys_only'` / `'combined_recovery'`) → `setGlobal paid_ransom=false, ransom_decision_made=true`, `completeTask: make_ransom_decision`

The previously-orphaned `ink/m02_terminal_ransom_interface.ink` (which duplicated this flow as ink) has been **deleted** — terminals are not ink-driven.
